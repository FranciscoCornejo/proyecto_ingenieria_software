# Fuentes y alcance

Esta versión reemplaza la propuesta anterior para la solicitud de menor complejidad:
solo cálculos locales sin persistencia. La versión anterior se conserva por separado.
No se editó `sources/` ni se redistribuyeron documentos del curso.

Base académica consultada al construir el proyecto:
- `Flujo_colaborativo_Git_GitHub_Ayudantia_v2.pptx` del chat “laboratorios”, 11
  diapositivas: ramas, interfaces, tareas pequeñas, evidencia, PR, revisión y pruebas
  antes de incorporar al proyecto común (especialmente diapositivas 4–10).
- `Proyecto_Integrador_Ingenieria_de_Software_2026-2_v6-1.docx`, §§1–5 y 8:
  trazabilidad, construcción, pruebas e integración; sistema paralelo de referencia
  del ayudante y proyectos propios de los equipos.
- `Programa_IngSoftware_2026-2-1.docx`, §§3 y 6: resultados de aprendizaje y EVA4
  el 26/11/2026. No se presume que todos los contenidos disponibles ya se impartieron.

Este laboratorio enseña el flujo colaborativo solicitado; no reemplaza los proyectos
propios ni satisface por sí solo todas las evidencias del Proyecto Integrador.
Sin almacenamiento por solicitud del usuario. La fuente dice persistencia “cuando
corresponda”, no obliga a incorporar una base en cada práctica.

Los temas de módulos, estructura, versiones Python/Flask y criterios técnicos son
propuestas de implementación. No son rúbricas ni requisitos retrospectivos.
Persiste una diferencia entre programa §6 (calificación final única del proyecto)
y Proyecto Integrador §§5/7 (seguimiento evaluado). La resuelve el docente; aquí no
se asignan notas o porcentajes.

Complemento técnico subordinado:
- https://flask.palletsprojects.com/en/stable/blueprints/
- https://flask.palletsprojects.com/en/stable/patterns/appfactories/
- https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches

No se usa Git Flow ni se exige una herramienta gráfica específica.
