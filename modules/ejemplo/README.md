# Ejemplo docente
Convierte kilómetros a metros. No guarda datos ni modifica el servidor.
Abrir `/modulos/ejemplo/`, escribir 2 y convertir: resultado 2000 metros.
Regla: admite valores entre 0 y 1.000.000; rechaza texto y negativos.
`logic.py` calcula; `__init__.py` recibe la petición; la plantilla muestra el resultado.
Es una referencia separada de las nueve funcionalidades de estudiantes.
